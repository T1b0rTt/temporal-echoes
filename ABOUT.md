# Über Temporal Echoes

> **Temporal Echoes** ist ein tiefgründiges Idle-/Incremental-Spiel mit 5 Prestige-Ebenen, entwickelt mit Vue.js 3 und TypeScript.

## Spielkonzept

In Temporal Echoes manipulierst du Zeit selbst. Durch geschickte Ressourcen-Produktion und strategisches Prestiging baust du ein Zeitempire auf, das immer größer wird - bis hin zu temporales Dimensionen und beyond.

## Entwickler

- **Lead Developer:** Tibor
- **Inspiration:** Antimatter Dimensions, Revolution Idle, Generic Idle Game Template

## Technologien

| Technologie | Verwendung |
|------------|-----------|
| Vue.js 3 | Frontend Framework |
| TypeScript | Typsichere Entwicklung |
| Pinia | State Management |
| Vite | Build Tooling |
| break_infinity.js | Große Zahlen (bis 1e9e15) |
